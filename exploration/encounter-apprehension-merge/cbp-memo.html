Intro

United States Border Patrol (USBP) releases apprehension and encounter data in separate sheets. While general encounters include all types of interactions at the border, Title 8 inadmissibles are recorded under the Office of Field Operations (OFO) rather than the USBP. Therefore, the USBP encounters datasets include only Title 8 apprehensions and Title 42 expulsions. On the other hand, USBP apprehensions data covers Title 8 apprehensions only.

Because intended difference between the USBP encounters datasets and the USBP apprehensions datasets is the pandemic-era Title 42 expulsions in the encounters dataset, we aim to consolidate encounters and apprehensions into one, comprehensive dataset that can be filtered depending on title_of_authority.

  • Original logic:
    • If statute_charge contains 8 USC -> Title 8
    • If statute_charge is NA or missing -> Title 42
    • Otherwise -> NA

Unique Value Exploration

To consolidate these apprehensions and encounters datasets, we attempt to use the statute_charge field to indicate whether an encounter is a Title 8 apprehension or Title 42 expulsion. First, we explore the unique values in this field. *To be filled in after law student report?

Title 42 CBP Dashboard Count Comparison

start_date <- as.Date("2020-03-20")
end_date <- as.Date("2023-05-11")

official_t42 <- cross_reference_file |>
  filter(
    Component == "U.S. Border Patrol",
    `Title of Authority` == "Title 42"
  ) |>
  mutate(
    month_number = match(
      str_to_upper(`Month (abbv)`),
      str_to_upper(month.abb)
    ),
    calendar_year = as.integer(`Fiscal Year`) -
      if_else(month_number >= 10L, 1L, 0L),
    month = make_date(calendar_year, month_number, 1)
  ) |>
  filter(between(
    month,
    floor_date(start_date, "month"),
    floor_date(end_date, "month")
  )) |>
  group_by(month) |>
  summarise(
    official_title42 = sum(`Encounter Count`, na.rm = TRUE),
    .groups = "drop"
  )

encounters_t42 <- encounters_edited |>
  filter(between(
    as.Date(encounter_datetime), start_date, end_date),
    title_of_authority == "Title 42"
  ) |>
  mutate(month = floor_date(as.Date(encounter_datetime), "month")) |>
  count(month, name = "assigned_title42")

comparison <- official_t42 |>
  left_join(encounters_t42, by = "month") |>
  mutate(
    difference = assigned_title42 - official_title42,
    pct_difference = 100 * difference / na_if(official_title42, 0)
  )

print(comparison, n = Inf)
